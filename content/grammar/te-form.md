The **te-form** is the most versatile verb form in Japanese. On its own it links clauses ("do X and Y"), and with helper verbs it builds requests, progressive tenses, permission, and much more.

## Formation

The godan rules are the same sound changes as the [ta-form](#/grammar/past-ta).

| Dictionary ending | Change | Example |
| ----------------- | ------ | ------- |
| う, つ, る (godan) | って | 買う → 買って, 待つ → 待って, 帰る → 帰って |
| む, ぶ, ぬ | んで | 読む → 読んで, 遊ぶ → 遊んで, 死ぬ → 死んで |
| く | いて | 書く → 書いて |
| ぐ | いで | 泳ぐ → 泳いで |
| す | して | 話す → 話して |
| る (ichidan) | て | 食べる → 食べて, 見る → 見て |
| Irregular | | する → して, 来る → 来て (きて) |
| **Exception** | | 行く → **行って** |

Adjectives and nouns:

- I-adjectives: い → くて (安くて). いい → よくて.
- Na-adjectives and nouns: で (静かで, 学生で).

## Uses

| Use | Example |
| --- | ------- |
| Sequence: "and then" | 起きて、顔を洗った |
| Listing qualities: "and" | 安くて美味しい |
| Manner or means | 歩いて行く |
| Cause (mild) | 遅くなって、すみません |
| Request | 見てください |
| Ongoing state | 読んでいる |
| Permission | 入ってもいい |
| Prohibition | 入ってはいけない |

## Examples

- 窓を開けて、外を見ました。 — I opened the window and looked outside.
- 朝ご飯を食べて、学校に行きます。 — I eat breakfast and go to school.
- この店は安くて、美味しいです。 — This shop is cheap and tasty.
- 兄は医者で、姉は弁護士です。 — My older brother is a doctor and my older sister is a lawyer.
- 駅まで歩いて行きましょう。 — Let's walk to the station.
- 遅れて、すみません。 — Sorry for being late.
- ちょっと待って。 — Wait a moment.

## Sequence

A chain of te-forms gives actions in order: シャワーを浴びて、着替えて、出かけた. The **last verb sets the tense and politeness** for the whole chain, so the te-forms themselves have no tense.

## Te-form + から

て + から emphasises "after doing": 手を洗ってから食べる (eat after washing hands). See [Mae ni / ato de](#/grammar/mae-ni-ato-de).

## Casual requests

In casual speech, the te-form alone is a request: 見て！ (Look!), 貸して (Lend it to me).

## Pitfalls

- 行く → 行って, not 行いて. This is the most common error.
- Watch for godan る-verbs: 帰る → 帰って, 切る → 切って (but 着る → 着て).
- Te-form linking implies a close connection. For contrast, use が or けど instead: 高いけど美味しい.
- 言って (from 言う, say) and 行って (from 行く, go) are both pronounced いって. In kana-only text, context tells them apart.
