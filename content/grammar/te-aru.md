**てある** (te-form + ある) describes a **state that results from someone's intentional action**. 窓が開けてある = "the window has been opened (by someone, on purpose) and is open". The focus is on the current state, while implying that a person did it deliberately, often as preparation.

## Formation

**Transitive verb** in te-form + ある. The object usually takes **が** (or は).

| Verb | Te-aru | Meaning |
| ---- | ------ | ------- |
| 書く | 書いてある | has been written |
| 置く | 置いてある | has been placed |
| 開ける | 開けてある | has been opened |
| 貼る | 貼ってある | has been stuck up |
| 用意する | 用意してある | has been prepared |

Polite: てあります. Past: てあった.

## Examples

- 黒板に名前が書いてあります。 — A name is written on the blackboard.
- 机の上に花が飾ってある。 — Flowers have been arranged on the desk.
- ホテルはもう予約してあります。 — I've already booked the hotel.
- 冷蔵庫にビールが冷やしてあるよ。 — There's beer chilling in the fridge.
- 壁にポスターが貼ってありました。 — A poster was stuck on the wall.
- この部屋はエアコンがつけてある。 — The air conditioning has been switched on in this room.

## てある vs ている

The difference depends on the verb type:

| Pattern | Verb type | Meaning | Example |
| ------- | --------- | ------- | ------- |
| が + intransitive + ている | intransitive | a state, no agent implied | 窓が開いている (The window is open) |
| が + transitive + てある | transitive | a state someone created on purpose | 窓が開けてある (The window has been left open) |
| を + transitive + ている | transitive | someone is doing it now | 窓を開けている (Someone is opening the window) |

So 電気がついている just says the light is on, while 電気がつけてある suggests someone switched it on for a reason.

## てある vs ておく

Both relate to preparation:

- **ておく** focuses on the action of preparing: ビールを冷やしておく (I'll chill some beer in advance).
- **てある** focuses on the resulting state: ビールが冷やしてある (Beer has been chilled).

See [Te-oku](#/grammar/te-oku).

## Particle choice

The thing affected is normally marked with が or は, because the sentence describes its state. を + てある exists too, emphasising the preparation done by the speaker: 資料をコピーしてあります (I've copied the documents already).

## Pitfalls

- てある only works with **transitive** verbs. 開いてある is wrong; use 開いている.
- The person who did the action is almost never mentioned.
- Don't confuse with the existence verb ある on its own: ペンがある (There is a pen).
