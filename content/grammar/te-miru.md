**てみる** (te-form + みる, "see") means "do something **to see** how it goes": try it out, give it a go. You actually do the action, and the point is to find out the result or experience.

## Formation

Te-form + みる. みる is an ichidan verb and is written in hiragana in this pattern.

| Verb | Te-miru |
| ---- | ------- |
| 食べる | 食べてみる |
| 着る | 着てみる |
| 行く | 行ってみる |
| 聞く | 聞いてみる |
| する | してみる |

Common forms: てみます, てみた, てみたい (want to try), てみてください (please try), てみよう (let's try), てみたら？ (why don't you try?).

## Examples

- この服、着てみてもいいですか。 — May I try this on?
- 初めて納豆を食べてみた。 — I tried natto for the first time.
- 分からなければ、先生に聞いてみたら？ — If you don't understand, why not ask the teacher?
- いつか北海道に行ってみたいです。 — I'd like to go to Hokkaido someday.
- このアプリ、使ってみてください。便利ですよ。 — Try using this app. It's handy.
- もう一度電話してみます。 — I'll try calling once more.
- 考えてみると、彼の言ったことは正しかった。 — Thinking it over, what he said was right.

## てみる vs ようとする

English "try" covers two ideas, and Japanese separates them:

| Pattern | Meaning | Example |
| ------- | ------- | ------- |
| てみる | do it and see what happens | 刺身を食べてみた (I tried sashimi; I ate it) |
| volitional + とする | attempt, make an effort (may fail) | ドアを開けようとした (I tried to open the door) |

So "I tried to sleep but couldn't" is 寝ようとしたけど、寝られなかった, not 寝てみたけど. See [Volitional form](#/grammar/volitional).

## Softening

てみる often makes suggestions and plans sound lighter: 聞いてみます (I'll ask and see) is less committal than 聞きます. With requests, てみてください sounds like a friendly recommendation rather than an order.

## Pitfalls

- Write みる in hiragana; 見る here is a common learner error (though you will see it occasionally).
- てみる is about real action. If you didn't actually do the thing, use ようとする.
- てみたら at the start of a clause can mean "when I tried": 食べてみたら、美味しかった (When I tried it, it was delicious).
