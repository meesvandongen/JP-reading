**と** has three main jobs: joining nouns in a complete list ("and"), marking a partner ("with"), and marking quoted speech or thought.

## Uses

| Use | Pattern | Example |
| --- | ------- | ------- |
| Complete list | N と N | パンと牛乳 |
| Together with | Person + と | 友達と行く |
| Reciprocal partner | Person + と + verb | 彼と結婚する |
| Comparison | N と N と、どちら | 犬と猫と、どちらが好き？ |
| Quotation | 「...」と / plain form + と | 「はい」と言った |
| Same / different | N と同じ / N と違う | 前と同じ |

## Examples

- 朝ご飯はパンと卵を食べました。 — I had bread and eggs for breakfast.
- 週末、家族と海に行きました。 — I went to the sea with my family at the weekend.
- 姉は来月、高校の同級生と結婚します。 — My sister is marrying a high-school classmate next month.
- 田中さんは「すぐ行きます」と言いました。 — Mr. Tanaka said, "I'll come right away."
- 明日は雨が降ると思います。 — I think it will rain tomorrow.
- この店は前と同じ味ですね。 — This shop's food tastes the same as before, doesn't it?
- コーヒーと紅茶と、どちらがいいですか。 — Which would you prefer, coffee or tea?

## と vs や

と lists **all** the items: パンと卵 means "bread and eggs (and that's it)". や lists **examples**: パンや卵 means "things like bread and eggs". Use と when the list is complete.

## と only joins nouns

English "and" can join anything, but と only joins **nouns**. To connect verbs or adjectives, use the [te-form](#/grammar/te-form): 安くて美味しい (cheap and tasty), 起きて顔を洗う (get up and wash my face). Joining sentences uses そして or the te-form.

## Quotation

と marks what someone said, thought or wrote. Direct quotes go in 「」; indirect quotes use the plain form: 行くと言った (said they would go), いいと思う (I think it's good). Casually, と becomes って: 行くって言ってた.

## Pitfalls

- 一緒に often goes with と: 友達と一緒に (together with friends). It is optional but natural.
- Some verbs need と for the partner, not に: 結婚する, 喧嘩する (fight), 話す (talk with). 会う can take either: 友達と会う (meet up, mutual) or 友達に会う (meet, run into).
- Do not confuse this と with the conditional と ("when/if"), which follows a verb: 春になると暖かくなる. See [Conditional と](#/grammar/conditional-to).
