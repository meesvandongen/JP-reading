**べき** expresses what one **should** or **ought to** do, based on duty, morality or common sense. べきだ is stronger and more judgemental than the gentle advice of ほうがいい.

## Formation

Dictionary form + べきだ.

| Before | Example |
| ------ | ------- |
| Verb | 行くべきだ |
| する | するべきだ / すべきだ |
| I-adjective | 高くあるべきだ (formal, rare) |
| Na-adjective / noun | 静かであるべきだ, 公平であるべきだ |

| Pattern | Meaning |
| ------- | ------- |
| べきだ | should, ought to |
| べきではない | should not |
| べきだった | should have (but didn't) |
| べきではなかった | shouldn't have |
| べき + noun | the ... one should ... (やるべきこと, things one should do) |

する has a classical short form **すべき**, which is very common: 勉強すべきだ.

## Examples

- 約束は守るべきだ。 — You should keep your promises.
- 学生はもっと勉強すべきです。 — Students ought to study more.
- 人の悪口を言うべきではない。 — One shouldn't speak ill of others.
- もっと早く病院に行くべきだった。 — I should have gone to the hospital sooner.
- 今やるべきことを先にやろう。 — Let's first do what needs to be done now.
- 政治家は国民に対して正直であるべきだ。 — Politicians ought to be honest with the people.

## べき vs ほうがいい

| べき | ほうがいい |
| ---- | ---------- |
| moral duty, principle | practical advice |
| strong, can sound preachy | softer, more personal |
| 謝るべきだ (You ought to apologise) | 謝ったほうがいい (It'd be better to apologise) |

When giving advice to someone directly, especially a superior, べき can sound like a lecture. ほうがいいですよ or 〜たらどうですか are gentler. べき is natural in opinions, essays and debates, or about yourself.

## べき vs はず vs なければならない

| Pattern | Meaning |
| ------- | ------- |
| べき | ought to (moral or rational judgement) |
| はず | it's expected to be the case (logic) |
| なければならない | must (rule or necessity) |

"He should be home" (expectation) is 家にいるはずだ, not いるべきだ.

## Pitfalls

- べき attaches to the dictionary form only. Past and negative go on だ: 行くべきだった, 行くべきではない. Saying 行ったべき or 行かないべき is wrong.
- Don't use べき for rules or laws that are compulsory; use なければならない.
- べき is less common in casual conversation; ほうがいい and しなきゃ are more frequent there.
