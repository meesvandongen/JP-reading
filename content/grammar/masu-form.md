The **masu-form** is the polite way to end a sentence with a verb. It is what you use with strangers, colleagues, shop staff and teachers, and it is usually the first verb form learners meet.

## Building the stem

Every masu-form is **stem + ます**. How you get the stem depends on the verb group.

| Group | Rule | Dictionary | Masu-form |
| ----- | ---- | ---------- | --------- |
| Godan (u-verbs) | change final u-sound to i-sound | 書く | 書きます |
| | | 飲む | 飲みます |
| | | 話す | 話します |
| | | 待つ | 待ちます |
| | | 買う | 買います |
| | | 帰る | 帰ります |
| Ichidan (ru-verbs) | drop る | 食べる | 食べます |
| | | 見る | 見ます |
| Irregular | | する | します |
| | | 来る | 来ます (きます) |

## Conjugations

| Form | Ending | Example |
| ---- | ------ | ------- |
| Present / future | ます | 行きます (go, will go) |
| Negative | ません | 行きません |
| Past | ました | 行きました |
| Past negative | ませんでした | 行きませんでした |
| Let's | ましょう | 行きましょう |
| Shall we? | ましょうか | 行きましょうか |
| Won't you? | ませんか | 行きませんか |

## Examples

- 毎日日本語を勉強します。 — I study Japanese every day.
- 私はお酒を飲みません。 — I don't drink alcohol.
- 昨日、友達と映画を見ました。 — I saw a film with a friend yesterday.
- 今朝は朝ご飯を食べませんでした。 — I didn't eat breakfast this morning.
- そろそろ帰りましょう。 — Let's head home soon.
- 窓を開けましょうか。 — Shall I open the window?
- 今度、一緒に飲みに行きませんか。 — Would you like to go for a drink sometime?

## Tense

Japanese has no separate future tense. 行きます means both "I go" and "I will go"; context and time words decide.

## The stem on its own

The masu-stem (書き, 食べ) is useful elsewhere: purpose with motion verbs (買いに行く, go to buy), the [tai-form](#/grammar/tai-form) (食べたい), [nagara](#/grammar/nagara) (食べながら), [sugiru](#/grammar/sugiru) and [yasui / nikui](#/grammar/yasui-nikui). Some stems are also nouns: 休み (holiday), 帰り (way home).

## Pitfalls

- **Ru-verb or u-verb?** Verbs ending in -eru or -iru are usually ichidan, but some are godan: 帰る → 帰ります, 入る → 入ります, 走る → 走ります, 知る → 知ります.
- In casual conversation with friends, masu-forms sound distant. Use the [plain form](#/grammar/plain-form) instead.
- The masu-form is polite but not humble or honorific. For higher politeness, see [Sonkeigo](#/grammar/keigo-sonkeigo) and [Kenjougo](#/grammar/keigo-kenjougo).
