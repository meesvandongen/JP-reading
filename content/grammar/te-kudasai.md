**てください** makes a polite request or gives an instruction: "please do X". Attach ください to the [te-form](#/grammar/te-form). For "please don't", use the nai-form + **でください**.

## Formation

| Pattern | Example | Meaning |
| ------- | ------- | ------- |
| te-form + ください | 見てください | please look |
| nai-form + でください | 見ないでください | please don't look |
| Noun + を + ください | 水をください | water, please |

## Examples

- ここに名前を書いてください。 — Please write your name here.
- もう少しゆっくり話してください。 — Please speak a little more slowly.
- ちょっと待ってください。 — Please wait a moment.
- 教室で携帯電話を使わないでください。 — Please don't use mobile phones in the classroom.
- 気にしないでください。 — Please don't worry about it.
- すみません、駅までの道を教えてください。 — Excuse me, please tell me the way to the station.
- コーヒーを一つください。 — One coffee, please.

## Politeness levels

てください is polite, but it is still a **directive**. Teachers, doctors, signs and announcements use it freely, but asking a favour of a superior with it can sound a bit commanding. Softer, more polite options, from casual to formal:

| Form | Feel |
| ---- | ---- |
| 見て | casual (friends, family) |
| 見てくれる？ | casual favour |
| 見てください | polite request or instruction |
| 見てくれませんか | polite favour |
| 見てもらえませんか | polite favour, softer |
| 見ていただけませんか | very polite |
| ご覧ください | honorific (sonkeigo) |

Asking with a negative question (〜ませんか) leaves room for the listener to refuse, which is why it sounds more polite.

## Noun + をください

With a thing rather than an action, use noun + を + ください: 切符を二枚ください (Two tickets, please). In shops, many people say お願いします instead: これ、お願いします.

## Honorific requests

In formal settings you will see お + stem + ください: お待ちください (please wait), お入りください (please come in). For する-nouns: ご注意ください (please be careful). See [Sonkeigo](#/grammar/keigo-sonkeigo).

## Pitfalls

- Do not use ください with the plain or masu-form: 書くください and 書きますください are wrong.
- ないでください, not なくてください.
- Friends rarely say てください to each other. A bare te-form (見て) or てね sounds more natural.
