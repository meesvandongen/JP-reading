**はず** is a noun meaning "expectation". はずだ expresses the speaker's **confident expectation based on reasoning or knowledge**: "it should be", "it must be", "it's supposed to". It is not about obligation, but about what is logically expected.

## Formation

はず is a noun, so it attaches like a noun modifier.

| Before | Example |
| ------ | ------- |
| Verb | 来るはず, 来たはず, 来ないはず |
| I-adjective | 高いはず |
| Na-adjective | 静か**な**はず |
| Noun | 学生**の**はず |

| Pattern | Meaning |
| ------- | ------- |
| はずだ / はずです | should be (expected) |
| はずがない / はずはない | can't possibly be |
| はずだった | was supposed to (but didn't) |

## Examples

- 田中さんはもうすぐ来るはずです。 — Mr. Tanaka should be here soon.
- 三時に出たから、もう着いているはずだ。 — He left at three, so he should have arrived by now.
- この店は有名だから、美味しいはずだ。 — This shop is famous, so it should be good.
- 鍵はかばんに入れたはずなのに、ない。 — I'm sure I put the key in my bag, but it's not there.
- 彼がそんなことを言うはずがない。 — There's no way he would say something like that.
- 今日は休みのはずですよ。 — Today should be a holiday, you know.
- 会議は十時に始まるはずだったが、まだ始まらない。 — The meeting was supposed to start at ten, but it hasn't started yet.

## はずがない: strong denial

はずがない (or はずはない) means "there's no way that", "it can't be": そんなはずはない (That can't be right!). It's a strong statement based on logic or belief.

Compare:

| Phrase | Meaning |
| ------ | ------- |
| 来ないはずだ | He is expected not to come. |
| 来るはずがない | There's no way he'll come. |

## はず vs べき vs つもり

| Pattern | Meaning |
| ------- | ------- |
| はず | logical expectation ("it should be the case") |
| べき | moral obligation or advice ("one ought to") |
| つもり | the speaker's own intention |

English "should" covers both はず and べき, so be careful: "He should be home" (expectation) is 家にいるはずだ, while "You should apologise" (advice) is 謝るべきだ.

## Pitfalls

- Don't use はず about your own deliberate actions: 明日行くはずです sounds like you are not in control of yourself. Use つもり or 予定.
- はず needs a reasonable basis. For guesses without much evidence, use でしょう or かもしれない.
- Remember な and の: 静かなはず, 学生のはず.
