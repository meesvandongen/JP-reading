A **nominalizer** turns a verb or clause into a noun, so it can take particles like が, を and は. English does this with "-ing" or "to": "**Swimming** is fun", "I like **to read**". Japanese uses **の** or **こと** after the plain form.

## Formation

Plain form + の / こと. Na-adjectives take な, nouns take な or である.

| Before | Example |
| ------ | ------- |
| Verb | 泳ぐの, 泳ぐこと |
| Past | 見たの, 見たこと |
| I-adjective | 高いの |
| Na-adjective | 静かなの, 静かなこと |

## Examples

- 私は本を読むのが好きです。 — I like reading books.
- 泳ぐのは楽しい。 — Swimming is fun.
- 彼が来るのを待っています。 — I'm waiting for him to come.
- 子供が公園で遊んでいるのが見えた。 — I could see the children playing in the park.
- 私の趣味は写真を撮ることです。 — My hobby is taking photos.
- 日本語を話すことは難しくない。 — Speaking Japanese isn't difficult.
- 鍵をかけるのを忘れた。 — I forgot to lock the door.
- 一番大切なことは、諦めないことだ。 — The most important thing is not giving up.

## When to use の vs こと

Often both work, but there are clear cases where only one is possible.

**Only の:**

- With perception verbs: 見る, 聞く, 見える, 聞こえる, 感じる. 彼が歌うのを聞いた (I heard him sing).
- With 待つ, 手伝う, 止める (stop someone): 子供が宿題をするのを手伝った.
- In the emphasis pattern "X のは Y だ": 私が欲しいのはこれだ (What I want is this).

**Only こと:**

- Before だ / です as a definition: 趣味は旅行することです.
- In fixed patterns: ことができる (can), ことがある (have done), ことにする (decide), ことになる (it has been decided).
- In rules and formal written statements: 廊下を走ることを禁止する (Running in the corridors is prohibited).

**Feel:** の is more concrete, immediate and conversational; こと is more abstract and formal.

## こと as a noun

こと is also a regular noun meaning "thing, matter" (abstract): 大切なこと (an important thing), 昨日のこと (what happened yesterday). Physical things use もの instead.

## Patterns built on こと

| Pattern | Meaning |
| ------- | ------- |
| 辞書形 + ことができる | can do |
| た形 + ことがある | have done before |
| 辞書形 + ことがある | sometimes do |
| 辞書形 + ことにする | decide to do |
| 辞書形 + ことになる | it has been decided that |

## Pitfalls

- Don't confuse nominalizer の with explanatory の / んです: 行くのです means "it's that I'm going", not "going". See [The explanatory んです](#/grammar/n-desu).
- "I like X" with a verb needs a nominalizer: 読むのが好き, not 読むが好き.
