The **nai-form** is the plain negative: 食べない (don't eat), 行かない (won't go). It is the casual counterpart of ません, and it is the base of many patterns such as ないでください, なければならない and なくてもいい.

## Formation

| Group | Rule | Dictionary | Nai-form |
| ----- | ---- | ---------- | -------- |
| Godan | change u-sound to a-sound + ない | 書く | 書かない |
| | | 読む | 読まない |
| | | 話す | 話さない |
| | | 待つ | 待たない |
| | | 帰る | 帰らない |
| | **う → わ** | 買う | 買わない |
| Ichidan | drop る + ない | 食べる | 食べない |
| | | 見る | 見ない |
| Irregular | | する | しない |
| | | 来る | 来ない (こない) |
| Special | | ある | ない |

Note the two irregular points: verbs ending in う become **わ**ない (買わない, not 買あない), and ある (to exist) has the negative just **ない**.

The nai-form conjugates like an i-adjective: 食べなかった (didn't eat), 食べなくて (not eating, and...), 食べなければ (if (I) don't eat).

## Examples

- 私は肉を食べない。 — I don't eat meat.
- 今日は学校に行かない。 — I'm not going to school today.
- 彼の名前が思い出せない。 — I can't remember his name.
- 時間がないから、急ごう。 — We don't have time, so let's hurry.
- 分からない言葉があったら、聞いてください。 — If there are words you don't understand, please ask.
- 心配しないでください。 — Please don't worry.
- 誰も来ないね。 — Nobody's coming, huh.

## Related patterns

| Pattern | Meaning | Example |
| ------- | ------- | ------- |
| ないでください | please don't | 写真を撮らないでください |
| ないで | without doing | 朝ご飯を食べないで出かけた |
| なくてもいい | don't have to | 来なくてもいい |
| なければならない | must | 行かなければならない |
| ないほうがいい | had better not | 無理しないほうがいい |

## Adjectives and nouns

- I-adjectives: い → くない (高くない).
- Na-adjectives and nouns: じゃない / ではない (静かじゃない, 学生じゃない).

## Polite negative

ません is the standard polite negative. You can also add です to the nai-form (食べないです), which is common in conversation but slightly less formal.

## Pitfalls

- **ないで vs なくて.** ないで is used for "without doing" and requests. なくて expresses cause: 分からなくて困った (I didn't understand, so I was in trouble).
- **Questions with ない** are often invitations: 行かない？ (Won't you come?).
- The godan verbs that look like ru-verbs take ら: 帰る → 帰らない, 知る → 知らない.
