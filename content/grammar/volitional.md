The **volitional form** expresses the speaker's will: "let's do" when inviting, "I'll do" when deciding. It is the plain counterpart of **ましょう**.

## Formation

| Group | Rule | Example |
| ----- | ---- | ------- |
| Godan | change u-sound to o-sound + う | 行く → 行こう, 飲む → 飲もう, 話す → 話そう, 待つ → 待とう, 帰る → 帰ろう, 買う → 買おう |
| Ichidan | drop る + よう | 食べる → 食べよう, 見る → 見よう |
| する | しよう | |
| 来る | 来よう (こよう) | |

Polite: masu-stem + ましょう (行きましょう).

## Uses

| Pattern | Meaning | Example |
| ------- | ------- | ------- |
| Volitional (alone) | let's / I'll | 行こう |
| Volitional + か | shall we? / shall I? | 手伝おうか |
| Volitional + と思う | I'm thinking of doing | 行こうと思う |
| Volitional + とする | try to, be about to | 寝ようとする |

## Examples

- もう遅いから、帰ろう。 — It's late, so let's go home.
- 今度の日曜日、一緒に映画を見よう。 — Let's watch a film together this Sunday.
- 重そうだね。持とうか。 — That looks heavy. Shall I carry it?
- 夏休みに沖縄へ行こうと思っています。 — I'm thinking of going to Okinawa for the summer holidays.
- 来年から毎日運動しようと思う。 — I think I'll start exercising every day from next year.
- ドアを開けようとしたが、鍵がかかっていた。 — I tried to open the door, but it was locked.
- 家を出ようとした時、電話が鳴った。 — Just as I was about to leave home, the phone rang.

## Intentions: ようと思う

Volitional + と思う expresses a plan or intention that the speaker has just formed or is considering. ようと思っている (the te-iru form) suggests an intention held for some time. Compare with [tsumori](#/grammar/tsumori), which is a firmer plan.

## Attempts: ようとする

ようとする means "try to (but may fail)" or "be about to". It differs from てみる, which means actually trying something out. See [Te-miru](#/grammar/te-miru).

## Polite invitations

ましょう is a direct "let's". To invite someone more softly, use ませんか: 一緒に行きませんか (Won't you come with me?). Replying 行きましょう accepts enthusiastically.

## Pitfalls

- Plain 行こう is for friends. With superiors, even ましょう can sound like you're taking charge; 〜ませんか or いかがですか is safer.
- The vowel is long: 行こう is ikō, not iko.
- ようと思う is for the speaker's own intentions. For others, use ようと思っている or と言っている.
