The **ta-form** is the plain past tense: 食べた (ate), 行った (went), した (did). It is the casual counterpart of ました. If you know the [te-form](#/grammar/te-form), you already know the ta-form: just replace て with た (and で with だ).

## Formation

| Dictionary ending | Change | Example |
| ----------------- | ------ | ------- |
| う, つ, る (godan) | った | 買う → 買った, 待つ → 待った, 帰る → 帰った |
| む, ぶ, ぬ | んだ | 読む → 読んだ, 遊ぶ → 遊んだ, 死ぬ → 死んだ |
| く | いた | 書く → 書いた |
| ぐ | いだ | 泳ぐ → 泳いだ |
| す | した | 話す → 話した |
| る (ichidan) | た | 食べる → 食べた, 見る → 見た |
| Irregular | | する → した, 来る → 来た (きた) |
| **Exception** | | 行く → **行った** |

Adjectives and nouns:

- I-adjectives: い → かった (高かった). いい → よかった.
- Na-adjectives and nouns: だった (静かだった, 雨だった).

## Examples

- 昨日、新しい靴を買った。 — I bought new shoes yesterday.
- 先週、京都に行った。 — I went to Kyoto last week.
- この本はもう読んだ。 — I've already read this book.
- 子供のころ、よく川で泳いだ。 — I often swam in the river as a child.
- 「宿題、した？」「うん、した。」 — "Did you do your homework?" "Yeah, I did."
- 駅で会った人は親切だった。 — The person I met at the station was kind.
- あ、財布を家に忘れた！ — Oh, I left my wallet at home!

## Past or completed?

た marks that something is **completed**, not only that it happened in the past. So it can translate English present perfect ("I've already eaten": もう食べた) and even describe things just noticed: あ、バスが来た！ (Oh, the bus is here!). In relative clauses it can refer to a completed action in the future: 日本に着いたら連絡します (When I've arrived in Japan, I'll contact you).

## Other uses

- **Modifying nouns:** 昨日見た映画 (the film I saw yesterday).
- **Advice:** た + ほうがいい = "you'd better": 早く寝たほうがいい.
- **Experience:** た + ことがある = "have done before": 富士山に登ったことがある.
- **Lists of actions:** たり〜たりする. See [Tari-tari](#/grammar/tari-tari).
- **Conditional:** たら. See [Conditional tara](#/grammar/conditional-tara).

## Pitfalls

- 行く is the only common verb that breaks the rule: 行った, not 行いた.
- Ichidan vs godan ending in る: 切る (godan, cut) → 切った; 着る (ichidan, wear) → 着た.
- For "not yet", use the te-iru negative, not the past negative: まだ食べていない (I haven't eaten yet). See [Past negative](#/grammar/past-negative).
