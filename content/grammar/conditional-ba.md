The **ば-form** expresses a condition: "if X, then Y". It emphasises the **condition itself**, often as what is needed for a good result. It is common in proverbs, advice and general statements.

## Formation

| Type | Rule | Example |
| ---- | ---- | ------- |
| Godan | change u-sound to e-sound + ば | 行く → 行けば, 読む → 読めば, 買う → 買えば |
| Ichidan | drop る + れば | 食べる → 食べれば, 見る → 見れば |
| する | すれば | |
| 来る | 来れば (くれば) | |
| Negative | ない → なければ | 行かなければ |
| I-adjective | い → ければ | 高い → 高ければ, いい → よければ |
| Na-adjective / noun | なら(ば) | 静かなら, 学生なら |

## Examples

- 安ければ、買います。 — If it's cheap, I'll buy it.
- この薬を飲めば、すぐ治りますよ。 — If you take this medicine, you'll get better soon.
- 急げば、まだ間に合う。 — If we hurry, we'll still make it.
- 時間があれば、手伝ってください。 — If you have time, please help.
- 勉強しなければ、合格できない。 — If you don't study, you can't pass.
- どうすればいいですか。 — What should I do?
- ちりも積もれば山となる。 — Even dust, piled up, becomes a mountain.

## ばいい: asking for advice

**ばいい** means "should" or "it would be good to". どうすればいいですか (What should I do?) and どこで買えばいいですか (Where should I buy it?) are extremely common questions.

## Wishes and regrets

ばよかった means "I wish I had": もっと早く来ればよかった (I should have come earlier).

## Restriction on the main clause

When the ば-clause contains an **action verb**, the main clause usually cannot be a request, command, invitation or intention:

- Unnatural: 駅に着けば、電話してください。
- Natural: 駅に着いたら、電話してください。

This restriction does **not** apply when the ば-clause is a state (adjectives, ある, いる, できる, the negative): 時間があれば、来てください is fine.

## ば〜ほど

ば + dictionary form + ほど means "the more ..., the more ...": 練習すればするほど上手になる (The more you practise, the better you get).

## Pitfalls

- Na-adjectives and nouns use なら(ば), not だれば: 学生なら.
- ば tends to sound a little formal or logical; in casual speech たら is more common for one-off situations.
- The negative なければ also appears in "must" patterns: 行かなければならない. See [Nakereba naranai](#/grammar/nakereba-naranai).
