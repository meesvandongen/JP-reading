Both **から** and **ので** mean "because" or "so". They attach to the end of the **reason clause**, which comes **first**: [reason] から [result]. This is the reverse of English "X because Y".

## Formation

| Before | から | ので |
| ------ | ---- | ---- |
| Verb | 行くから | 行くので |
| I-adjective | 高いから | 高いので |
| Na-adjective | 静かだから | 静か**な**ので |
| Noun | 雨だから | 雨**な**ので |
| Polite | 行きますから | 行きますので (very polite) |

Note: before ので, だ becomes **な**.

## Examples

- 暑いから、窓を開けて。 — It's hot, so open the window.
- 明日はテストがあるから、今日は早く寝る。 — I have a test tomorrow, so I'm going to bed early tonight.
- 雨なので、試合は中止になりました。 — The match was cancelled because of rain.
- 道が混んでいたので、遅れてしまいました。 — The roads were busy, so I ended up being late.
- 「どうして来なかったの？」「熱があったから。」 — "Why didn't you come?" "Because I had a fever."
- 危ないですから、白線の内側までお下がりください。 — It is dangerous, so please stand behind the white line.
- 少し気分が悪いので、帰ってもいいですか。 — I'm feeling a bit unwell, so may I go home?

## から vs ので

| から | ので |
| ---- | ---- |
| subjective, speaker's own reasoning | more objective, natural cause and effect |
| direct, can sound assertive | softer, more polite |
| fine before commands, invitations, opinions | less natural before strong commands |
| can end a sentence: 熱があったから。 | rarely ends a sentence |
| can take だ: だから, ですから | |

When **asking permission** or **apologising**, ので sounds more considerate: 用事があるので、お先に失礼します (I have an errand, so I'll leave first). Using から there can sound like an excuse.

## Ending with から / からです

To answer "why?", put から at the end: 好きだから (Because I like it). Polite: 好きだからです. You cannot end a sentence with ので in the same way in formal speech.

## だから and ですから

At the start of a sentence, だから / ですから means "therefore, that's why": 雨が降っている。だから、家にいる.

## Pitfalls

- Do not confuse "because" から (after a clause) with "from" から (after a noun): 東京から来た (came from Tokyo). See [Particles から and まで](#/grammar/particle-kara-made).
- てから means "after doing", not "because": 食べてから行く.
- Remember the な: 学生なので, 静かなので, not 学生ので.
