**Masu-stem + たい** means "want to do". 食べる → 食べたい (want to eat), 行く → 行きたい (want to go). The result behaves like an **i-adjective**, so it conjugates with くない, かった and so on.

## Formation

| Verb | Masu-stem | Tai-form |
| ---- | --------- | -------- |
| 食べる | 食べ | 食べたい |
| 行く | 行き | 行きたい |
| 飲む | 飲み | 飲みたい |
| する | し | したい |
| 来る | 来 (き) | 来たい (きたい) |

| | Plain | Polite |
| --- | --- | --- |
| Want to | 行きたい | 行きたいです |
| Don't want to | 行きたくない | 行きたくないです / 行きたくありません |
| Wanted to | 行きたかった | 行きたかったです |
| Didn't want to | 行きたくなかった | 行きたくなかったです |

## Examples

- 冷たい水が飲みたいです。 — I want to drink some cold water.
- いつか日本に住みたい。 — I want to live in Japan someday.
- 今日はどこにも行きたくない。 — I don't want to go anywhere today.
- 子供のころ、パイロットになりたかった。 — When I was a child, I wanted to be a pilot.
- 何が食べたい？ — What do you want to eat?
- 来年、富士山に登りたいと思っています。 — I'm thinking I'd like to climb Mt. Fuji next year.

## を or が?

The object can take either を or が: 水を飲みたい / 水が飲みたい. が puts slightly more emphasis on the object and feels more emotional; を is more common with longer phrases or when the verb is far from the object.

## Wanting things (nouns)

たい is only for actions. For wanting a **thing**, use **ほしい**: 新しい車がほしい (I want a new car).

## Other people's wishes

Japanese treats feelings as private. You can say 私は行きたい, but saying 田中さんは行きたい sounds odd, as if you can read his mind. For third persons, use:

- **たがる**: 弟はゲームをしたがっている (My brother wants to play games). Often sounds like an outsider's observation.
- **と言っている**: 行きたいと言っていた (He said he wants to go).
- **らしい / そうだ**: 行きたいらしい (Apparently he wants to go).

## Asking others

Asking a superior 〜たいですか directly (先生、コーヒーを飲みたいですか) is too blunt. Offer instead: コーヒーはいかがですか (Would you like some coffee?) or 飲みませんか.

## Pitfalls

- Softening: 〜たいと思います ("I think I'd like to") is more modest than a bare たいです.
- たい conjugates like an i-adjective, so 行きたいでした is wrong; use 行きたかったです.
